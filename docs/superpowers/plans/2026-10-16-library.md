# Library (Step 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users add books by ISBN (Open Library lookup with manual fallback), own graded copies, list/unlist/edit/remove them, and view their paginated library.

**Architecture:** Two new feature packages, `book` (shared `Book`, `Isbn` value object, `BookCatalog` port with an Open Library adapter) and `copy` (`Copy` aggregate holding all status/grade rules, `CopyService`, controllers). Same conventions as step 1: `web`/`service`/`domain`/`repository` layers, record DTOs, entities never leave the service layer, errors via `ApiException` subclasses.

**Tech Stack:** Java 21, Spring Boot (upgraded to latest 3.5.x in Task 1), Spring Data JPA, Flyway, PostgreSQL 16, Spring `RestClient`, JUnit 5, Mockito, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-16-library-design.md` (requirements: `BookSwapRequirementsSpec.md`, Epic B).

## Global Constraints

- Java release 21; Maven; base package `com.bookswap`; package-by-feature.
- Schema only via Flyway (`V2__books_and_copies.sql`), `spring.jpa.hibernate.ddl-auto=validate`; constraints enforced in the DB as well as in code.
- Optimistic locking (`@Version`) on `copy`.
- All list endpoints paginated; no N+1 (proved by a test).
- Error body is always the existing `ErrorResponse` (`{status, code, message, fieldErrors[], timestamp, path}`) via `ApiException`; no internals in messages.
- Authorization in the service layer: every copy operation takes the principal's id; another user's copy is a 404, never a 403.
- Tests never touch the network: integration tests use the `@Primary` stub `BookCatalog`.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (pass as a second `-m`).
- Test command for the whole suite: `mvn -B test` (surefire includes `*Test` and `*IT`). Single class: `mvn -B -q test -Dtest=ClassName`.

## Review Focus

- ISBN edge inputs: whitespace, hyphens, lowercase `x`, Unicode digits, NUL, over-long strings, ISBN-13 not starting 978/979 -> 400 `INVALID_ISBN`, never 500 (Task 2, Task 5).
- Manual title/author: blank, NUL, over 500 chars -> 400 per-field errors (Task 6).
- Catalog responses: empty `{}`, no authors, no cover, `http://` cover, garbage JSON, 5xx, timeout -> never a 500; unavailable maps to 503 / manual fallback (Task 4).
- Catalog data trusted into the DB: NUL characters and over-long strings from the catalog must not break the insert (Task 4).
- Page abuse: `size=100000`, negative page/size -> clamped, not a 500 or an OOM (Task 6).
- Concurrent first-add of the same ISBN by several users -> one `book` row, all copies created (Task 7).
- Reserved copy edited/unlisted/removed -> 409 `COPY_RESERVED` (Tasks 3, 6).

```java
package com.bookswap.book.domain;

import java.util.Locale;

/** A validated ISBN, always held in its 13-digit form so that ISBN-10 and ISBN-13 spellings compare equal. */
public final class Isbn {
    private static final int MAX_RAW_LENGTH = 32;

    private final String value;

    private Isbn(String value) {
        this.value = value;
    }

    public static Isbn parse(String raw) {
        if (raw == null || raw.length() > MAX_RAW_LENGTH) {
            throw new InvalidIsbnException();
        }
        String s = raw.strip().replace("-", "").replace(" ", "").toUpperCase(Locale.ROOT);
        // Explicit [0-9] on purpose: \d and Character.isDigit also match non-ASCII digits.
        if (s.length() == 10 && s.matches("[0-9]{9}[0-9X]") && validIsbn10(s)) {
            return new Isbn(toIsbn13(s));
        }
        if (s.length() == 13 && s.matches("[0-9]{13}")
                && (s.startsWith("978") || s.startsWith("979")) && validIsbn13(s)) {
            return new Isbn(s);
        }
        throw new InvalidIsbnException();
    }

    public String value() {
        return value;
    }

    private static boolean validIsbn10(String s) {
        int sum = 0;
        for (int i = 0; i < 10; i++) {
            char c = s.charAt(i);
            int digit = c == 'X' ? 10 : c - '0';
            sum += (10 - i) * digit;
        }
        return sum % 11 == 0;
    }

    private static boolean validIsbn13(String s) {
        return weightedSum13(s, 13) % 10 == 0;
    }

    private static String toIsbn13(String isbn10) {
        String body = "978" + isbn10.substring(0, 9);
        int check = (10 - weightedSum13(body, 12) % 10) % 10;
        return body + check;
    }

    private static int weightedSum13(String s, int digits) {
        int sum = 0;
        for (int i = 0; i < digits; i++) {
            sum += (s.charAt(i) - '0') * (i % 2 == 0 ? 1 : 3);
        }
        return sum;
    }

    @Override
    public boolean equals(Object o) {
        return o instanceof Isbn other && value.equals(other.value);
    }

    @Override
    public int hashCode() {
        return value.hashCode();
    }

    @Override
    public String toString() {
        return value;
    }
}
```

```java
package com.bookswap.book.repository;

import com.bookswap.book.domain.Book;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.data.jpa.repository.Modifying;
import org.springframework.data.jpa.repository.Query;
import org.springframework.data.repository.query.Param;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;

public interface BookRepository extends JpaRepository<Book, String> {

    /**
     * Race-safe first insert of a shared book: a concurrent insert of the same ISBN is a no-op, so callers
     * simply re-read afterwards. The CAST keeps PostgreSQL from typing a null cover as bytea.
     */
    @Transactional
    @Modifying
    @Query(value = "INSERT INTO book (isbn13, title, author, cover_url, created_at) "
            + "VALUES (:isbn13, :title, :author, CAST(:coverUrl AS varchar), :createdAt) "
            + "ON CONFLICT (isbn13) DO NOTHING", nativeQuery = true)
    int insertIfAbsent(@Param("isbn13") String isbn13, @Param("title") String title,
                       @Param("author") String author, @Param("coverUrl") String coverUrl,
                       @Param("createdAt") Instant createdAt);
}
```

```java
package com.bookswap.copy.domain;

import com.bookswap.book.domain.Book;
import jakarta.persistence.*;
import org.springframework.data.domain.Persistable;

import java.time.Instant;
import java.util.UUID;

/** A physical copy of a book. All grade/status rules live here, in one place. */
@Entity
@Table(name = "copy")
public class Copy implements Persistable<UUID> {

    @Id
    private UUID id;

    @Column(name = "owner_id", nullable = false, updatable = false)
    private UUID ownerId;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "isbn13", nullable = false, updatable = false)
    private Book book;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private ConditionGrade grade;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private CopyStatus status;
```

```java
package com.bookswap.book.catalog;

import com.bookswap.book.domain.Isbn;
import com.fasterxml.jackson.databind.JsonNode;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientException;

import java.util.Optional;

public class OpenLibraryCatalog implements BookCatalog {

    private static final Logger log = LoggerFactory.getLogger(OpenLibraryCatalog.class);
    private static final int MAX_TEXT = 500;
    private static final int MAX_COVER_URL = 1000;
    static final String UNKNOWN_AUTHOR = "Unknown author";

    private final RestClient client;

    public OpenLibraryCatalog(RestClient client) {
        this.client = client;
    }

    @Override
    public Optional<BookDetails> lookup(Isbn isbn) {
        JsonNode body;
        try {
            // Only the normalized, digits-only ISBN is ever placed in the URL.
            body = client.get()
                    .uri("/api/books?bibkeys=ISBN:{isbn}&format=json&jscmdata=data", isbn.value())
                    .retrieve()
                    .body(JsonNode.class);
        } catch (RestClientException e) {
            log.warn("Open Library lookup failed for {}: {}", isbn, e.toString());
            throw new CatalogUnavailableException(e);
        }
        return parse(isbn, body);
    }

    private Optional<BookDetails> parse(Isbn isbn, JsonNode body) {
        if (body == null || !body.isObject()) {
            throw malformed(isbn, "response is not a JSON object");
        }
        JsonNode entry = body.get("ISBN:" + isbn.value());
        if (entry == null || entry.isNull()) {
            return Optional.empty();
        }
        if (!entry.isObject()) {
            throw malformed(isbn, "entry is not an object");
        }
        String title = clean(text(entry.get("title")));
        if (title == null) {
            throw malformed(isbn, "entry has no title");
        }
        String author = null;
        JsonNode authors = entry.get("authors");
        if (authors != null && authors.isArray() && !authors.isEmpty()) {
            author = clean(text(authors.get(0).get("name")));
        }
        return Optional.of(new BookDetails(title, author != null ? author : UNKNOWN_AUTHOR, cover(entry.get("cover"))));
    }

    private static String cover(JsonNode cover) {
        if (cover == null || !cover.isObject()) {
            return null;
        }
        String url = text(cover.get("medium"));
        if (url == null || !url.startsWith("https://") || url.length() > MAX_COVER_URL || url.indexOf('\u0000') >= 0) {
            return null;
        }
        return url;
    }

    private static String text(JsonNode node) {
        return node != null && node.isTextual() ? node.asText() : null;
    }

    /** Catalog text goes into the DB: drop NULs (PostgreSQL rejects them), trim, cap the length, reject blanks. */
    private static String clean(String s) {
        if (s == null) {
            return null;
        }
        String cleaned = s.replace("\u0000", "").strip();
        if (cleaned.isEmpty()) {
            return null;
        }
        return cleaned.length() > MAX_TEXT ? cleaned.substring(0, MAX_TEXT) : cleaned;
    }

    private static CatalogUnavailableException malformed(Isbn isbn, String why) {
        log.warn("Open Library returned an unusable payload for {}: {}", isbn, why);
        return new CatalogUnavailableException();
    }
}
```
Note: `body(JsonNode.class)` on non-JSON text throws a `RestClientException` subclass (`RestClientException`/`HttpMessageNotReadableException` wrapped) — covered by the garbage-body test. If a garbage body surfaces a non-`RestClientException` (e.g. raw `HttpMessageNotReadableException`), widen the catch to `RestClientException | org.springframework.http.converter.HttpMessageNotReadableException`.

```java
package com.bookswap.book.service;

import com.bookswap.book.catalog.BookCatalog;
import com.bookswap.book.catalog.BookDetails;
import com.bookswap.book.catalog.CatalogUnavailableException;
import com.bookswap.book.domain.Book;
import com.bookswap.book.domain.Isbn;
import com.bookswap.book.repository.BookRepository;
import com.bookswap.book.web.LookupResponse;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

import java.time.Clock;
import java.util.Optional;

/**
 * Deliberately not @Transactional: the catalog HTTP call must not hold a database connection, and
 * each repository call is its own short transaction.
 */
@Service
public class BookService {

    private static final Logger log = LoggerFactory.getLogger(BookService.class);

    private final BookRepository books;
    private final BookCatalog catalog;
    private final Clock clock;

    public BookService(BookRepository books, BookCatalog catalog, Clock clock) {
        this.books = books;
        this.catalog = catalog;
        this.clock = clock;
    }

    public LookupResponse lookup(Isbn isbn) {
        Optional<Book> local = books.findById(isbn.value());
        if (local.isPresent()) {
            return LookupResponse.from(local.get());
        }
        BookDetails details = catalog.lookup(isbn).orElseThrow(BookNotFoundException::new);
        return new LookupResponse(isbn.value(), details.title(), details.author(), details.coverUrl(),
                LookupResponse.Source.CATALOG);
    }

    /** Local book first, then the catalog, then the caller's manual title and author. */
    public Book resolveForCopy(Isbn isbn, String manualTitle, String manualAuthor) {
        Optional<Book> local = books.findById(isbn.value());
        if (local.isPresent()) {
            return local.get();
        }
        Optional<BookDetails> fromCatalog = Optional.empty();
        try {
            fromCatalog = catalog.lookup(isbn);
        } catch (CatalogUnavailableException e) {
            log.warn("Catalog unavailable while adding {}; falling back to manual details", isbn);
        }
        BookDetails details = fromCatalog.orElseGet(() -> manual(manualTitle, manualAuthor));
        if (details == null) {
            throw new BookDetailsRequiredException();
        }
        books.insertIfAbsent(isbn.value(), details.title(), details.author(), details.coverUrl(), clock.instant());
        // Re-read: a concurrent insert of the same ISBN may have won, and the stored row is the truth.
        return books.findById(isbn.value()).orElseThrow();
    }

    private static BookDetails manual(String title, String author) {
        if (title == null || title.isBlank() || author == null || author.isBlank()) {
            return null;
        }
        return new BookDetails(title, author, null);
    }
}
```

```java
package com.bookswap.copy.service;

import com.bookswap.book.domain.Book;
import com.bookswap.book.domain.Isbn;
import com.bookswap.book.service.BookService;
import com.bookswap.common.web.PageResponse;
import com.bookswap.copy.domain.ConditionGrade;
import com.bookswap.copy.domain.Copy;
import com.bookswap.copy.domain.CopyNotFoundException;
import com.bookswap.copy.domain.CopyStatus;
import com.bookswap.copy.repository.CopyRepository;
import com.bookswap.copy.web.AddCopyRequest;
import com.bookswap.copy.web.CopyResponse;
import com.bookswap.user.service.UserService;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageRequest;
import org.springframework.data.domain.Pageable;
import org.springframework.data.domain.Sort;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.util.UUID;

/**
 * Every method takes the authenticated principal's id as {@code ownerId}; a copy that is not the caller's is
 * indistinguishable from a missing one. Step 4 will add "cancel proposed proposals" calls to the grade,
 * unlist and remove paths here: this is the single place those rules will live.
 */
@Service
public class CopyService {
    static final int MAX_PAGE_SIZE = 100;

    private final CopyRepository copies;
    private final BookService bookService;
    private final UserService userService;
    private final Clock clock;

    public CopyService(CopyRepository copies, BookService bookService, UserService userService, Clock clock) {
        this.copies = copies;
        this.bookService = bookService;
        this.userService = userService;
        this.clock = clock;
    }

    /** Not @Transactional: resolving the book may call the catalog over HTTP. */
    public CopyResponse add(UUID ownerId, AddCopyRequest request) {
        Isbn isbn = Isbn.parse(request.isbn());
        Book book = bookService.resolveForCopy(isbn, request.title(), request.author());
        return CopyResponse.from(copies.save(new Copy(ownerId, book, request.grade(), clock.instant())));
    }

    @Transactional(readOnly = true)
    public PageResponse<CopyResponse> list(UUID ownerId, CopyStatus status, int page, int size) {
        Pageable pageable = PageRequest.of(Math.max(page, 0), Math.min(Math.max(size, 1), MAX_PAGE_SIZE),
                Sort.by(Sort.Order.desc("createdAt"), Sort.Order.asc("id")));
        Page<Copy> result = status == null
                ? copies.findByOwnerId(ownerId, pageable)
                : copies.findByOwnerIdAndStatus(ownerId, status, pageable);
        return PageResponse.from(result.map(CopyResponse::from));
    }

    @Transactional(readOnly = true)
    public CopyResponse get(UUID ownerId, UUID id) {
        return CopyResponse.from(load(ownerId, id));
    }

    @Transactional
```
